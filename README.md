# My Personal Portfolio Website

A clean and minimal personal portfolio website built from scratch using pure HTML, CSS, and JavaScript. This was my first ever personal website!

---

## About

This is my personal portfolio where I showcase my projects, skills, and background. It was designed to be simple, elegant, and fully responsive across all devices.

---

## Features

- section with profile photo
- About me section
- Projects showcase with hover animations
- Skills & tools grid
- Contact form (powered by Formspree)
- Smooth scroll-reveal animations
- Fully responsive on mobile

---

## Built With

- HTML
- CSS
- JavaScript
